# CLAIM AUDIT TABLE — HEDO-HVSC PUBLICATION AUDIT

| Original Claim / Overstatement | Scientific Problem / Defect | Empirical / Code Evidence in Final Artifacts | Corrected Defensible Claim in Final Paper |
| :--- | :--- | :--- | :--- |
| **"Strictly contractive discrete Hamiltonian operator"** | The discrete update does not constitute a proven contractive mapping for arbitrary learned weights. | `pre_training_diagnostic.json` shows unforced trajectory: $170.82 \to 170.65 \to 170.92 \to 171.64 \to 172.80 \to 174.38$. Energy is not strictly monotonically decreasing. | **"Hamiltonian-inspired discrete dissipative transformation with positive damping coefficient $\beta=0.05$."** |
| **"Proven dissipative operator with guaranteed bounded energy"** | Mathematical overclaim. The diagnostic indicates representation transformation, not a formal universal discrete Lyapunov theorem. | Discrete integration uses forward Euler step ($\Delta t=0.1$) with learned $\mathbf{W}_q, \mathbf{W}_p$. | **"Motivated by classical dissipative Hamiltonian dynamics to introduce a stabilizing inductive bias."** |
| **"Guaranteed $\mathcal{O}(L)$ linear complexity proven by $R^2=0.9998$"** | Statistical $R^2$ fit is an empirical measurement, not an asymptotic complexity proof. | Measured latency: $L=16$ ($2.89\text{ ms}$) to $L=256$ ($38.60\text{ ms}$). | **"The recurrent scan executes a linear number of state transitions per token, yielding algorithmic $\mathcal{O}(L)$ scaling for fixed state dimensions, supported by approximately linear empirical measurements."** |
| **"Superior / universal robustness across corruptions"** | False generalization across test perturbations. | `robustness_results.json`: Clean ($\Delta = -0.87\%$), Gauss 0.05 ($\Delta = -0.47\%$), Gauss 0.10 ($\mathbf{\Delta = +0.50\%}$), Brightness ($\Delta = -0.60\%$). | **"Mixed corruption profile: achieves $+0.50\%$ gain under severe Gaussian noise ($\sigma=0.10$), but lower Mean Recall on the other three perturbation conditions."** |
| **"Significantly outperforms the SSD baseline"** | Overstatement of clean retrieval performance. | `master_results.csv`: Baseline ($48.25\% \pm 0.47\%$) vs. Full ($48.28\% \pm 0.59\%$). Paired delta: $+0.03\% \pm 0.20\%$. | **"Full HEDO-HVSC achieves retrieval performance essentially comparable to the controlled SSD baseline on clean Flickr8k ($48.28\%$ vs. $48.25\%$, $\Delta = +0.03\%$)."** |
| **"State-of-the-Art (SOTA) multimodal retrieval model"** | False positioning against external heavy-backbone models. | Backbones are frozen ViT-B/16 and RoBERTa-base with $\sim 0.42\text{M}$ trainable parameters evaluated on Flickr8k. | **"A controlled proof-of-concept architectural study investigating state-space recurrence in vision-language metric learning."** |
| **"Hardware-optimized / Native Mamba-2 kernel"** | Inaccurate library attribution. | Code uses custom PyTorch sequential/chunk-wise tensor loops, not official `mamba_ssm` CUDA kernels. | **"Custom PyTorch SSD-style recurrent state-space block with state-continuous chunk recurrence."** |
| **"Bidirectional cross-modal state feedback in HVSC"** | Misleading description of inference dataflow. | Retrieval inference computes image and text embeddings strictly independently with zero cross-modal attention. | **"Unimodal deterministic posterior-mean inference at test time; symmetric KL divergence is applied strictly during training."** |
