\section{Hardware and Execution Environment Provenance}
\label{sec:supp_hardware_env}
All 12 training and evaluation runs were executed on a dedicated cloud compute instance under identical software and hardware specifications:
\begin{itemize}
    \item \textbf{Accelerator Hardware:} NVIDIA Tesla T4 GPU ($16\,\text{GB}$ GDDR6 VRAM, Compute Capability 7.5).
    \item \textbf{Host System:} Linux / Windows Server x86\_64 multi-core platform.
    \item \textbf{Software Stack:} PyTorch 2.1.0+cu121, Torchvision 0.16.0+cu121, CUDA 12.2, Driver 535.104.05.
    \item \textbf{Pretrained Model Weights:} \texttt{timm} Vision Transformer (\texttt{vit\_base\_patch16\_224}, 86.6 M parameters, frozen), HuggingFace Transformers \texttt{roberta-base} (124.6 M parameters, frozen).
    \item \textbf{Determinism Protocol:} CUDA deterministic algorithms enabled, random seed explicitly set for Python random, NumPy, and PyTorch (CPU and CUDA).
\end{itemize}

\section{Additional Implementation Details and Reproducibility}
\label{sec:supp_reproducibility}
\begin{itemize}
    \item \textbf{Optimization Routine:} AdamW optimizer with $\beta_1=0.9, \beta_2=0.999$, weight decay $10^{-4}$, initial learning rate $\eta_{\text{max}}=2\times 10^{-4}$, cosine decay schedule down to $\eta_{\text{min}}=10^{-6}$ over 8 epochs.
    \item \textbf{Gradient Management:} Global gradient norm clipping at $1.0$ applied before each optimizer update step.
    \item \textbf{Batch Formation:} 64 images per batch paired with 5 captions each, yielding an effective batch size of 320 image-caption pairs.
    \item \textbf{Model Checkpointing:} Validation Mean Recall evaluated at the conclusion of every epoch; the highest-performing checkpoint is selected for final evaluation on the certified held-out test split.
\end{itemize}
